# Python for AI

A progressive learning repository focused on the Python foundations needed for data science, machine learning and artificial intelligence.

The goal of this repository is not to collect isolated exercises. It documents a structured progression from core Python to the tools and programming habits used in real AI/ML projects.

## Philosophy

Each topic should move through three stages:

1. **Understand** the concept.
2. **Implement** it without copying a complete solution.
3. **Reuse** it inside a slightly more realistic AI/data task.

This repository will evolve alongside my studies in applied artificial intelligence.

## Environment

Recommended: Python 3.11+.

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter:

```bash
jupyter lab
```
