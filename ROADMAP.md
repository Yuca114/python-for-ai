# Roadmap

## Phase 1 — Core Python

### Module 01: Python fundamentals
- Variables
- Numeric types
- Strings
- Booleans
- Lists
- Dictionaries
- Conditions
- Loops
- Functions

**Milestone:** write small programs without relying on notebook-only code.

### Module 02: Working with data
- Reading files
- Exceptions
- Comprehensions
- Modules
- Useful standard-library tools

**Milestone:** load and transform a small dataset with plain Python.

## Phase 2 — Scientific Python

### Module 03: NumPy
- Arrays
- Shapes
- Indexing
- Broadcasting
- Vectorized operations
- Basic linear algebra

**Milestone:** replace manual loops with vectorized numerical operations.

### Module 04: pandas
- Series and DataFrames
- Filtering
- Missing values
- Grouping
- Merging
- Basic feature creation

**Milestone:** perform an exploratory data analysis workflow.

### Module 05: Visualization
- Matplotlib fundamentals
- Histograms
- Scatter plots
- Bar charts
- Labels and figure interpretation

**Milestone:** communicate useful conclusions from data.

## Phase 3 — Engineering habits for ML

### Module 06: Reusable Python
- Functions
- Type hints
- Packages
- Classes where appropriate
- Separation between notebooks and reusable code

### Module 07: Testing
- pytest
- Assertions
- Edge cases
- Reproducibility

**Milestone:** build code that can be trusted and reused by later ML projects.

## Final mini-project

A small end-to-end exploratory data project using Python, NumPy, pandas and Matplotlib. The final project will become the bridge to the next repository: `fraud-detection-ml`.
